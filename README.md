# 100 ДВЕРЕЙ — оновлення каталогу та прайсів

Ця збірка запускає сайт разом із локальним сервером та базою SQLite. Імпорт прайсу записує зміни в серверну базу, тому не потрібно щоразу публікувати новий HTML.

## Запуск у Windows

1. Розпакуйте архів у звичайну папку.
2. Запустіть `start_windows.bat`.
3. При першому запуску встановляться залежності Python. Для цього потрібен Інтернет.
4. Введіть пароль адміністратора та відкрийте `http://127.0.0.1:8000`.

Не закривайте вікно сервера, поки працюєте із сайтом.

## Додавання та оновлення прайсу

1. Відкрийте **Оновлення прайсів**.
2. Для нового бренду виберіть **Додати виробника**, для наявного — **Оновити прайс**.
3. Виберіть тип дверей і PDF. Назви відомих виробників (зокрема LEADOR Express/Premium, CITY LINE Express, KORFAD та STILDORS PRESTO) визначаються окремо.
4. Перевірте список розпізнаних моделей, цін, кольорів і скла та натисніть **Підтвердити імпорт**.

PDF із виділюваним текстом аналізується за координатами таблиці: програма шукає цінові заголовки й комірки, зіставляє їх із назвами моделей, пропускає розділи погонажу та комплектуючих і збирає доступні декори/скло з відповідних колонок. Якщо один модельний ряд має кілька цін, у попередньому перегляді показується найнижча стартова ціна. Моделі, яких немає в оновленому прайсі, залишаються в базі.

Для сканованого PDF спочатку потрібне OCR із текстовим шаром. PDF.js та імпортер Excel завантажуються з Інтернету під час використання. Якщо таблиця незвична або заголовки відсутні, імпорт може попросити підготувати пошуковий PDF чи Excel; завжди перевіряйте попередній перегляд до збереження.

## Додавання вручну

1. Виберіть **Додати виробника** та вкажіть його назву.
2. Перейдіть на вкладку **Ввести вручну**. Заповніть спільні кольори/декори, скло, особливості та ціни.
3. Додайте назву кожної моделі. Якщо ціни або характеристики відрізняються, відкрийте для неї **Окремі параметри**.
4. Перевірте попередній перегляд і підтвердьте імпорт. Для наявного виробника використовуйте **Оновити прайс**: попередній перегляд покаже нові, змінені й незмінені моделі. Моделі, яких у прайсі немає, залишаться в каталозі.

Порожні комірки кольору в імпортованій таблиці трактуються як відсутні дані: вони не створюють порожніх плиток і не стирають уже відомі кольори під час оновлення.

## Перенесення наявної бази

Перед заміною старої папки збережіть її `data\catalog.sqlite3` та `data\imports`. Зупиніть старий сервер і скопіюйте ці файли в однойменну папку нової збірки. Так збережуться виробники, моделі та історія прайсів. Якщо бази ще не було, каталог створиться під час першого запуску.

`data\catalog.sqlite3` містить каталог та історію цін; `data\imports` зберігає завантажені оригінали прайсів. Робіть резервну копію папки `data` перед великими оновленнями.

Цей запуск прив'язаний до `127.0.0.1` і призначений для роботи на цьому комп'ютері.

## Публікація на GitHub Pages

У папці `docs` уже підготовлена статична версія: `docs/index.html`. Вона працює без Python-сервера, а каталог і імпорт прайсів обробляються у браузері.

1. Додайте папку проєкту до GitHub-репозиторію.
2. У репозиторії відкрийте **Settings → Pages**. У джерелі публікації виберіть основну гілку репозиторію (наприклад, `main`) і папку `/docs`, потім збережіть налаштування.
3. Після публікації відкрийте видану GitHub Pages адресу. Для імпорту прайсів потрібне підключення до Інтернету.

**Як опублікувати оновлений каталог:** імпортуйте прайс у розділі керування базою; натисніть **«Завантажити оновлений сайт»**; замініть отриманим `index.html` файл `docs/index.html` у репозиторії та зафіксуйте зміни. Після завершення публікації новий каталог з'явиться на сайті.

На GitHub Pages каталог зберігається локально в браузері. Імпорт, видалення або редагування в браузері одного користувача не змінює каталог інших відвідувачів, доки оновлений `docs/index.html` не буде опублікований. Серверна історія імпортів і збереження оригіналів прайсів тут недоступні. Дані, вбудовані в опублікований HTML, доступні відвідувачам сайту.
