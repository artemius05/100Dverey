Вхідні двері

Розділ створено. Для додавання виробників, моделей та характеристик вхідних дверей потрібен окремий прайс. Дані міжкімнатних дверей сюди не переносимо.

У списку лише моделі обраного виробника.
Меню активне — оберіть модель.
«Без скла» / «Без особливостей» — значення за замовчуванням, якщо характеристику не вдалося підтвердити в прайсі. Перевіряйте перед друком.

Вартість та кількість елементів:

Ціни для цієї моделі в прайсі не знайдені. Перевірте їх перед друком.

Друк кількох цінників

Друк на А4: 2 або 3 цінники — горизонтальний аркуш, 4 — вертикальний (2 × 2). Усі цінники на аркуші однакового розміру. Додавай різні цінники, а для зміни будь-якого натисни «Редагувати» біля нього. Після змін натисни «Зберегти зміни».

Локальна база браузера.

Підтримуються Excel XLS/XLSX, CSV/TSV, JSON, PDF із текстом і Word DOCX. Перед збереженням можна перевірити розпізнані моделі. Для сканованого PDF потрібне OCR, а старий DOC спочатку збережіть як DOCX.

Щоб створити виробника вручну, введіть його назву в полі вище. Нижче додайте моделі й спільні характеристики; для різних моделей можна розкрити «Окремі параметри».
